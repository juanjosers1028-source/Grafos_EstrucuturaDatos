# Grafos_EstructuraDatos
Integrantes:
Juan Jose Renteria
Jeronimo Hoyos
Salome Murillo

Cuando se ejecuta el código, el programa inicia mostrando un menú con diferentes opciones para administrar una red social representada mediante un grafo no dirigido. Primero, el usuario puede agregar personas al sistema, las cuales se almacenan como nodos dentro del grafo. Luego, se pueden crear amistades entre esos usuarios, y estas amistades se guardan en una matriz de adyacencia donde el valor 1 indica que existe conexión y 0 que no existe. A medida que el usuario utiliza el programa, este permite agregar y eliminar amistades, listar los amigos directos de una persona y sugerir nuevos amigos buscando usuarios que tengan amigos en común. Además, el programa puede encontrar el camino más corto entre dos usuarios utilizando el algoritmo BFS, recorriendo el grafo por niveles hasta encontrar la menor cantidad de conexiones necesarias para llegar de una persona a otra. Durante toda la ejecución, el sistema actualiza automáticamente la matriz del grafo para mantener organizada la información de las relaciones. Finalmente, el programa continúa funcionando dentro de un ciclo repetitivo hasta que el usuario selecciona la opción de salir.
